#샘플 파일 구성

토스페이먼츠가 제공하는 XPay 샘플 패키지는 연동에 필요한 라이브러리, 설정 파일, 결제 흐름을 구현한 샘플 페이지로 구성됩니다. 파일 구성은 개발 언어마다 다릅니다. 라이브러리 설치 방법은 설치 및 환경 구성을, 설정 파일은 conf 설정을 참고합니다.

참고 샘플 페이지의 기본 인코딩은 EUC-KR입니다. 샘플은 기본 사항만 담고 있으므로 상점 환경에 맞게 수정해서 사용합니다.

#샘플 페이지 흐름

결제 샘플 페이지는 아래 순서로 동작합니다. 언어별 코드는 XPayClient 호출 패턴을 참고합니다.

순서페이지역할
1sample_crossplatform결제 요청에 필요한 정보를 입력합니다.
2payreq_crossplatform입력된 정보로 XPay 인증결제창을 호출합니다.
3인증결제창구매자가 결제수단을 선택하고 추가 정보를 입력합니다.
4returnurl인증이 끝나면 LGD_PAYKEY(인증키)를 받아 부모 페이지인 payreq_crossplatform의 payment_return 함수로 전달합니다.
5payresLGD_PAYKEY로 최종 결제를 요청하고 결과를 처리합니다.

#공통 샘플 페이지

샘플 페이지는 언어별 확장자(.jsp, .php, .asp, .aspx)만 다르고 역할은 같습니다. 모두 상점 환경에 맞게 개발이 필요한 파일입니다.

파일설명작업 구분
sample_crossplatform.html결제를 위한 데이터 입력 페이지개발 필요
payreq_crossplatform인증결제창 호출 및 요청 페이지개발 필요
returnurl인증 결과 수신 및 전달 페이지개발 필요
payres최종 결제 요청 및 결과 처리 페이지개발 필요
cas_noteurl무통장(가상계좌) 할당, 입금 통보 결과 처리 페이지개발 필요
CashReceipt.html현금영수증 발급·취소를 위한 정보 입력 페이지개발 필요
CashReceipt현금영수증 발급·취소 요청 페이지개발 필요
Cancel.html전자결제 취소 요청을 위한 정보 입력 페이지개발 필요
Cancel취소 요청 페이지개발 필요
참고 모든 언어의 샘플은 같은 입력 페이지(.html)를 사용합니다. 각 기능 폴더의 README.md에 진입 페이지와 수정할 곳을 정리했습니다.

가상계좌 입금통보를 받는 cas_noteurl 페이지는 가상계좌 발급·변경을, 방화벽 설정은 방화벽 및 IP 정보를 함께 참고합니다.

라이브러리 파일은 Java 라이브러리 설치를 참고합니다.
