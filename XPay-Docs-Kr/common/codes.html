#기관 및 코드

결제 요청과 응답에서 사용하는 코드 값의 정의처입니다. 각 거래 페이지의 파라미터 설명은 이 문서를 참조합니다.

#결제수단 코드

#응답 코드

LGD_RESPCODE가 0000이면 성공, 그 외는 실패입니다. 실패 사유는 LGD_RESPMSG에 담깁니다.

설정 파일 관련 오류는 결제 요청이 서버에 도달하기 전에 발생합니다.

코드의미조치
0000성공-
10001lgdacom 디렉토리 설정을 읽지 못했습니다.XPayClient 초기화 시 넘기는 configPath가 lgdacom 폴더의 절대경로인지 확인하세요.
10002mall.conf 파일을 찾을 수 없습니다.lgdacom/conf/mall.conf 파일 존재 여부와 읽기 권한을 확인하세요.
10003lgdacom.conf 파일을 찾을 수 없습니다.lgdacom/conf/lgdacom.conf 파일 존재 여부와 읽기 권한을 확인하세요.

그 외 결제 실패 코드는 결제수단과 기관에 따라 달라집니다. 전체 목록은 별도 제공되는 결제수단별 오류코드 문서를 참고하세요.
