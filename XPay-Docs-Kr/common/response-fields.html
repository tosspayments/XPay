#거래 응답 필드

결제 승인 응답으로 내려오는 필드의 정의처입니다. 어느 결제수단에서 값이 채워지는지 함께 표시했습니다. 각 거래 페이지는 이 문서를 참조하며, 거래별 추가 필드는 해당 페이지에 정의됩니다.

제공 결제수단이 공통이면 모든 결제수단에서 값이 내려옵니다. 특정 결제수단만 표시된 필드는 다른 결제수단에서는 빈 값이거나 내려오지 않습니다.
파라미터최대길이설명제공 결제수단

LGD_MID15토스페이먼츠 발급 아이디공통
