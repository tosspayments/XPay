#방화벽 및 IP 정보

#방화벽 설정

방화벽은 신뢰할 수 없는 외부 네트워크가 내부 네트워크에 접근하지 못하도록 막는 보안 시스템입니다. 특정 포트나 IP의 트래픽을 필터링하는 방식 외에도 사용자 인증, 프록시, 주소 변환(NAT) 등의 방식이 있습니다.

XPayClient 연동에서는 두 방향의 통신이 방화벽을 통과할 수 있어야 합니다.

  • 아웃바운드: 상점 서버에서 XPay 게이트웨이로 보내는 결제, 취소, 조회 등의 요청입니다. 모든 상점에 필요합니다.
  • 인바운드: 토스페이먼츠에서 상점 서버로 보내는 가상계좌 입금통보입니다. 가상계좌를 사용하는 상점에만 필요합니다.

#포트를 허용해주세요

#API 요청용 443 포트

상점 서버에서 XPay 게이트웨이로 요청을 보내려면 HTTPS 통신에 쓰는 443 포트의 아웃바운드 트래픽이 허용되어 있어야 합니다.

#가상계좌 입금통보 수신 포트

가상계좌 입금통보는 LGD_CASNOTEURL에 설정한 주소로 전송됩니다. 입금통보는 표준 포트(HTTP 80, HTTPS 443)로만 수신할 수 있으므로 LGD_CASNOTEURL에는 80 또는 443 포트를 사용하는 주소를 설정하고, 방화벽에서 해당 포트의 인바운드 트래픽을 허용해주세요. 허용할 발신 IP는 아래 인바운드 IP 목록을 참고해주세요.

#인바운드 IP를 허용해주세요

가상계좌 입금통보를 사용하면서 IP 접근 제어 목록(ACL, Access Control List)으로 인바운드 트래픽을 제한하고 있다면, 아래 토스페이먼츠 입금통보 IP를 허용 목록에 추가해주세요. 허용하지 않으면 입금통보가 상점 서버에 도달하지 못합니다.

#아웃바운드 IP를 허용해주세요

상점 서버에 아웃바운드 방화벽이 적용되어 있다면, XPay 게이트웨이로 요청을 보낼 수 있도록 아래 IP를 허용 목록에 추가해주세요. 도메인 기반 허용을 지원하는 방화벽이라면 게이트웨이 도메인도 함께 등록해주세요. 기존 IP만 등록되어 있다면 신규 IP도 모두 추가해야 합니다.
