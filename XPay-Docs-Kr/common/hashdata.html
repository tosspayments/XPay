#해쉬데이터 생성

LGD_HASHDATA는 주문정보의 위변조를 막는 필수 파라미터입니다. 결제 요청 시 상점이 생성해 전달하고, 응답을 받은 뒤에는 같은 방식으로 다시 계산해 응답값과 일치하는지 검증해야 합니다.

LGD_MERTKEY는 상점키입니다. 절대 클라이언트(브라우저)에 노출되면 안 되며, 해쉬 생성은 반드시 서버에서 수행하세요. 상점키는 conf 설정에서 다루는 mall.conf에 저장됩니다.

#요청 해쉬

아래 값을 순서대로 이어붙인 문자열을 MD5로 해싱합니다.

순서파라미터설명
1LGD_MID상점아이디
2LGD_OID주문번호
3LGD_AMOUNT금액
4LGD_TIMESTAMP타임스탬프
5LGD_MERTKEY상점키
text
LGD_HASHDATA = MD5( LGD_MID + LGD_OID + LGD_AMOUNT + LGD_TIMESTAMP + LGD_MERTKEY )

#응답 해쉬

응답에 포함된 LGD_HASHDATA를 아래 규칙으로 재계산해 검증합니다. 값이 다르면 응답이 위조된 것으로 보고 결제를 성공 처리하지 마세요.

순서파라미터설명
1LGD_MID상점아이디
2LGD_OID주문번호
3LGD_AMOUNT금액
4LGD_RESPCODE응답코드
5LGD_TIMESTAMP타임스탬프
6LGD_MERTKEY상점키
text
LGD_HASHDATA = MD5( LGD_MID + LGD_OID + LGD_AMOUNT + LGD_RESPCODE + LGD_TIMESTAMP + LGD_MERTKEY )

요청 해쉬와 달리 LGD_RESPCODE가 포함됩니다. 순서를 지켜야 값이 일치합니다.

#라이브러리로 생성하기

XPayClient는 해쉬 생성 메소드를 제공합니다. MD5를 직접 구현하지 마세요. GetHashData()를 호출하면 상점키를 mall.conf에서 읽어 규칙에 맞게 계산합니다. 상점키를 코드에 넣지 않아도 되므로 노출 위험이 없습니다.

java
XPayClient xpay = new XPayClient();
xpay.Init(configPath, CST_PLATFORM);

if (LGD_TIMESTAMP == null || "".equals(LGD_TIMESTAMP)) {
    LGD_TIMESTAMP = xpay.GetTimeStamp();
}
String LGD_HASHDATA = xpay.GetHashData(LGD_MID, LGD_OID, LGD_AMOUNT, LGD_TIMESTAMP);

GetTimeStamp()로 타임스탬프를 만들면 해쉬 계산에 사용한 값과 결제창에 전달하는 값이 어긋나지 않습니다. 직접 생성한 타임스탬프를 쓴다면 해쉬 계산과 LGD_TIMESTAMP 파라미터에 같은 값을 사용해야 합니다.

생성한 해쉬는 결제창 호출 Form의 hidden 필드로 전달합니다.

html
<input type="hidden" name="LGD_TIMESTAMP" value="<%=LGD_TIMESTAMP%>" />
<input type="hidden" name="LGD_HASHDATA"  value="<%=LGD_HASHDATA%>" />
상점키(LGD_MERTKEY)는 mall.conf에만 두고, log_dir과 함께 웹에서 접근할 수 없는 경로에 배치하세요. 자세한 내용은 conf 설정을 참고하세요.

#영수증 링크 해쉬

매출전표와 현금영수증 출력 URL에 사용하는 authdata는 별도 규칙을 사용합니다.

text
authdata = MD5( LGD_MID + LGD_TID + LGD_MERTKEY )
원본 파일 common/hashdata.md
