#매출전표 분할등록

LGD_TXNAME ReceiptSubMall / ReceiptTrxDivide / ReceiptTrxSearch

하나의 거래를 여러 하위 상점의 매출전표로 분할 등록합니다. 하위상점 등록, 분할 등록, 분할 조회 3개 메소드를 사용합니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

#매출전표 분할 가맹점정보 요청 파라미터

파라미터필수최대길이설명
LGD_TXNAME미정-메소드 : CardAuth
LGD_MID필수15TossPayments에서 부여한 상점아이디 토스페이먼츠에서 발급한 상점아이디
LGD_SUBMALLID미정15분할전표 분할 가맹점 ID 영문,숫자, -, _ 만 사용가능(한글금지), 최대 15자
LGD_METHOD미정-SEARCH : 현재 등록되어 있는 분할 매출전표 내역 조회 REGISTER : 등록 ( LGD_PRODUCTINFO, 부분취소일 경우 LGD_STEPID 필수) CANCEL : 삭제 ( 부분취소일 경우 LGD_STEPID 필수)
LGD_COMPANYNAME미정60상점명
LGD_COMPANYADDRESS미정120상점주소
LGD_BUSINESSNUMBER미정15상점 사업자번호
LGD_TELNO미정45상점 연락처
LGD_CEONAME미정24상점 대표자명
LGD_TIMESTAMP선택14타임스탬프
LGD_HASHDATA필수-해쉬데이타 주문정보 위변조 방지용

#매출전표 분할 가맹점정보 응답 파라미터

파라미터최대길이설명
LGD_RESPCODE4응답코드 '0000' 이면 성공 이외는 실패
LGD_RESPMSG160응답메세지

LGD_TID미정24TossPayments 거래번호

#원거래 조회 응답 파라미터

파라미터최대길이설명
LGD_RESPCODE4응답코드 '0000' 이면 성공 이외는 실패
LGD_RESPMSG160응답메세지
LGD_PAYTYPE6결제수단코드
LGD_TRANSINFO-거래 상세 내역 reqdate : 거래시간(취소, 부분취소는 요청시간) status : 상태(A: 승인, C: 취소, P: 부분취소) amount : 금액(부분취소는 부분취소 요청금액) stepid: 부분취소 일련번호 * 아래 예시 참고 LGD_TRANSINFO 예시 10000원 승인 후 5000원 부분취소한 거래 {"transinfo":[{"reqdate":"20210317110637","status":"A","amount":"10000","stepid":""},{"reqdate":"20210318090000","status":"P","amount":"5000","stepid":"tossp20210317110637_1111"}]}

#오류 처리

LGD_RESPCODE가 0000이면 성공입니다. 전체 목록은 응답 코드를 참고하세요.
