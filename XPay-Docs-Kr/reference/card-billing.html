#카드 빌링 결제

LGD_TXNAME CardAuth

발급된 LGD_BILLKEY로 결제를 요청하는 자동결제 방식입니다. 비인증 결제와 LGD_TXNAME이 같지만 카드번호 대신 빌링키를 사용합니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

#카드빌링키 발급 요청 파라미터

파라미터필수최대길이설명
LGD_TXNAME미정-메소드 : CardAuth
LGD_MID필수15TossPayments에서 부여한 상점아이디 토스페이먼츠에서 발급한 상점아이디
LGD_OID필수64상점 주문번호(상점에서 작성한 거래번호) 영문 및 숫자로만 구성하며 주문별로 유일하게 생성
LGD_AMOUNT필수12결제금액 구분자 ',' 등이 없이 숫자로만 구성
LGD_PAN미정-빌링키 (LGD_BILLKEY)
LGD_INSTALL미정2할부개월 (2자리) ex) 00:일시불, 03:3개월
LGD_EXPYEAR미정2유효기간(년) (YY:2자리)
LGD_EXPMON미정2유효기간(월) (MM:2자리)
LGD_PIN미정2카드비밀번호 앞2자리
LGD_PRIVATENO미정10구매자 생년월일 6자리 (YYMMDD) or 사업자번호 10자리
VBV_ECI미정3고정값 : 010 (Key-in, 빌링)

#코드 예제

토스페이먼츠가 제공하는 JSP 샘플 CardAuth.jsp에서 빌링키 결제에 필요한 부분만 추린 코드입니다. 다른 언어의 샘플도 동일한 순서를 따릅니다.

java
<%@ page import="lgdacom.XPayClient.XPayClient" %>
<%
String configPath = "C:/lgdacom";  // 웹에서 접근할 수 없는 경로에 둡니다.

XPayClient xpay = new XPayClient();
if (!xpay.Init(configPath, CST_PLATFORM)) {
    // 초기화 실패. lgdacom.conf, mall.conf 설치 상태와 mall.conf의 "MID = mertkey" 등록을 확인하세요.
    return;
}

xpay.Init_TX(LGD_MID);
xpay.Set("LGD_TXNAME", "CardAuth");
xpay.Set("LGD_OID", LGD_OID);
xpay.Set("LGD_AMOUNT", LGD_AMOUNT);
xpay.Set("LGD_PAN", LGD_BILLKEY);                // 카드번호 대신 발급받은 빌링키
xpay.Set("LGD_INSTALL", LGD_INSTALL);            // 할부개월수 (일시불: 00)
xpay.Set("VBV_ECI", "010");
xpay.Set("LGD_BUYERPHONE", LGD_BUYERPHONE);
xpay.Set("LGD_BUYER", LGD_BUYER);
xpay.Set("LGD_BUYERID", LGD_BUYERID);
xpay.Set("LGD_BUYERIP", request.getRemoteAddr());
xpay.Set("LGD_PRODUCTINFO", LGD_PRODUCTINFO);

if (xpay.TX()) {
    if ("0000".equals(xpay.m_szResCode)) {
        // 결제 성공. 결과를 DB에 저장합니다.
        boolean isDBOK = true;  // DB 처리에 실패하면 false
        if (!isDBOK) {
            xpay.Rollback("상점 DB처리 실패로 인하여 Rollback 처리 [TID:" + xpay.Response("LGD_TID", 0)
                + ",MID:" + xpay.Response("LGD_MID", 0) + ",OID:" + xpay.Response("LGD_OID", 0) + "]");
        }
    } else {
        // 결제 실패. 실패 결과를 DB에 저장합니다.
    }
} else {
    // API 요청 실패. xpay.m_szResCode, xpay.m_szResMsg로 사유를 확인하고 실패 결과를 DB에 저장합니다.
}
%>

#확인 포인트

  • 빌링키 결제는 카드 비인증 결제와 같은 CardAuth 거래입니다. LGD_PAN에 카드번호 대신 발급받은 LGD_BILLKEY를 넣는다는 점만 다릅니다.
  • 샘플 CardAuth.jsp는 비인증 결제와 같은 파일이라 Key-in용 유효기간·비밀번호·생년월일 처리가 들어 있습니다. 빌링키 결제에서는 이 값을 보내지 않으므로 위 코드에서는 뺐습니다.
  • xpay.TX()가 true면 통신에 성공한 것이고, 결제 성공 여부는 xpay.m_szResCode가 0000인지로 판단합니다.
  • 결제는 성공했지만 상점 DB 저장에 실패했다면 xpay.Rollback()으로 자동취소합니다. 이 처리를 빠뜨리면 구매자는 결제됐는데 주문이 없는 상태가 됩니다.
  • 빌링키를 결제창에서 발급받는 방법은 결제창 빌링키 발급을 참고합니다.

출처: 샘플 TossPayments_CardBilling_JSP/CardAuth.jsp

#오류 처리

LGD_RESPCODE가 0000이면 성공입니다. 전체 목록은 응답 코드를 참고하세요.
