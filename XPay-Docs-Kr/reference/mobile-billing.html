#휴대폰 빌링 결제

LGD_TXNAME Mobile

휴대폰 결제를 자동결제로 사용합니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

#휴대폰빌링키 발급 인증 요청 (STEP1) 파라미터

파라미터필수최대길이설명
LGD_TXNAME미정-메소드 : CardAuth
LGD_STEP미정-STEP1 (고정값)
LGD_MID필수15TossPayments에서 부여한 상점아이디 토스페이먼츠에서 발급한 상점아이디
LGD_OID필수64상점 주문번호(상점에서 작성한 거래번호) 영문 및 숫자로만 구성하며 주문별로 유일하게 생성
LGD_AMOUNT필수12결제금액 구분자 ',' 등이 없이 숫자로만 구성
LGD_MOBILECOM미정1이동통신사 구분 (1:SKT / 2:KT / 3:LGU)
LGD_MOBILENUM미정15결제할 휴대폰번호
LGD_MOBILESSN미정7주민번호 앞 7자리
LGD_PRODUCTINFO필수128구매한 상품명
LGD_BUYER필수10구매자명

LGD_RESPMSG160응답메세지

LGD_TID24TossPayments 거래번호
LGD_AMOUNT12결제금액 구분자 ',' 등이 없이 숫자로만 구성
LGD_PAYTYPE6결제수단코드
LGD_MOBILECOM1이동통신사 구분 (1:SKT / 2:KT / 3:LGU)

#코드 예제

토스페이먼츠가 제공하는 JSP 샘플 MobileBilling.jsp에서 연동에 필요한 부분만 추린 코드입니다. 다른 언어의 샘플도 동일한 순서를 따릅니다.

java
<%@ page import="lgdacom.XPayClient.XPayClient" %>
<%
String configPath = "C:/lgdacom";

XPayClient xpay = new XPayClient();
if (!xpay.Init(configPath, CST_PLATFORM)) {
    // 환경파일 로드 실패. lgdacom.conf, mall.conf 설치 상태를 확인하세요.
    return;
}

xpay.Init_TX(LGD_MID);
xpay.Set("LGD_TXNAME", "Mobile");
xpay.Set("LGD_AUTHMODE", "BILLING");
xpay.Set("LGD_OID", LGD_OID);
xpay.Set("LGD_AMOUNT", LGD_AMOUNT);
xpay.Set("LGD_MOBILECOM", LGD_MOBILECOM);
xpay.Set("LGD_MOBILENUM", LGD_MOBILENUM);
xpay.Set("LGD_MOBILESSN", LGD_MOBILESSN);
xpay.Set("LGD_PRODUCTINFO", LGD_PRODUCTINFO);
xpay.Set("LGD_BUYER", LGD_BUYER);
xpay.Set("LGD_BILLKEY", LGD_BILLKEY);

if (xpay.TX()) {
    if ("0000".equals(xpay.m_szResCode)) {
        String respCode = xpay.Response("LGD_RESPCODE", 0);
        String tid      = xpay.Response("LGD_TID", 0);
        if ("0000".equals(respCode)) {
            // 성공. 거래 결과를 DB에 저장하세요.
            boolean isDBOK = true;
            if (!isDBOK) {
                xpay.Rollback("상점 DB 처리 실패로 인한 Rollback [TID:" + tid + "]");
            }
        }
    }
}
%>

#확인 포인트

  • xpay.m_szResCode는 통신 응답코드이고 LGD_RESPCODE는 거래 응답코드입니다. 둘 다 0000이어야 결제 성공입니다. 통신은 성공했지만 거래가 실패한 경우가 있으므로 반드시 두 값을 모두 확인하세요.
  • xpay.Response(파라미터명, 0)으로 응답값을 꺼냅니다. 두 번째 인자는 인덱스이며 같은 이름의 응답이 여러 개인 경우에만 0이 아닌 값을 사용합니다.
  • 승인은 성공했지만 상점 DB 저장에 실패했다면 xpay.Rollback()으로 자동취소하세요. 이 처리를 빠뜨리면 고객은 결제됐는데 주문이 없는 상태가 됩니다.
  • 응답 전체를 순회하려면 xpay.ResponseNameCount()와 xpay.ResponseName(i)를 사용합니다.

출처: 샘플 TossPayments_MobileBilling_JSP/TossPayments_MobileBilling_JSP/MobileBilling.jsp

#오류 처리

LGD_RESPCODE가 0000이면 성공입니다. 전체 목록은 응답 코드를 참고하세요.
