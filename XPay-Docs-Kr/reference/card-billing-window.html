#결제창 빌링키 발급

LGD_TXNAME CardAuth

통합결제창에서 구매자 인증을 거쳐 빌링키를 발급받습니다. PC와 모바일 모두 동일한 방식입니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

#빌링인증창 호출 요청 파라미터

파라미터필수최대길이설명
CST_PLATFORM미정-토스페이먼츠 서버와 통신하는 서버의 라이브/테스트 환경을 선택하는 파라미터 입니다. service (라이브 환경) 또는 test (테스트 환경)
CST_MID미정15TossPayments와 계약된 상점아이디
LGD_MID필수15TossPayments에서 부여한 상점아이디 토스페이먼츠에서 발급한 상점아이디
LGD_DOMAIN_URL미정-모듈 연결 URL 정보 "xpayvvip" 를 고정값 으로 사용합니다. (TLS1.2로 결제창 호출) xpayvvip TLS1.2로 결제창(인증)을 호출하기 위한 필수 파라미터이므로 임의로 수정 및 삭제를 해서는 안됩니다.
LGD_WINDOW_TYPE미정-결제창 호출 방식을 의미하며 결제창을 호출하는 디바이스 환경에 따라 고정된 값을 사용해야 합니다. PC 일 경우 "iframe" 사용. 모바일 디바이스일 경우 "submit" 사용.
LGD_RETURNURL필수255인증결과 응답수신페이지 URL 인증페이지와 동일한 프로트콜 및 호스트이어야 함 (인증페이지와 동일 디렉토리에 위치),
LGD_PAYWINDOWTYPE미정-인증요청구분 PC 일 경우 "CardBillingAuth" 사용. 모바일 디바이스일 경우 "CardBillingAuth_smartphone" 사용.
LGD_VERSION미정-사용 모듈 정보 위 파라미터를 누락한다고 서비스 이용이 불가능한 것은 아니지만 어떤 서비스를 사용하는지 판단을 위한 것으로 해당 파라미터는 수정 및 삭제 금지
LGD_ENCODING선택-결제창 호출 시 인코딩 방식 (기본값: EUC-KR) 을 설정합니다. 예) UTF-8 결제창 인증 완료 후 승인요청에 대한 서버응답의 인코딩 설정은 mall.conf 파일에서 UTF-8 사용일 경우 output_UTF8 = 1 을 사용하시면 됩니다. (EUR_KR 은 0 입니다.) 기본값 EUC-KR Form submit 방식으로 결제창 호출시 EUC-KR이외의 인코딩을 하는 경우만 사용
LGD_ENCODING_RETURNURL선택-결제창 인증결과 수신페이지의 호출문자 인코딩방식을 LGD_RETURNURL에 전달(기본값: EUC-KR) 합니다. 기본값 EUC-KR UTF-8로 넘기면 UTF-8로 인코딩된 값을 LGD_RETURNURL 에 전달
LGD_BUYERSSN미정6구매자 생년월일(또는 사업자번호)
LGD_CHECKSSNYN미정1구매자 생년월일 체크여부 체크를 원하면 Y로 설정하면 됩니다. (기본값 : N)

#코드 예제

토스페이먼츠가 제공하는 JSP 샘플 TossPayments_CardBilling_JSP에서 빌링키 발급에 필요한 부분만 추린 코드입니다. 다른 언어의 샘플도 동일한 순서를 따릅니다.

순서파일역할
1CardBillingAuth_Req.jsp빌링 인증창 호출
2returnurl.jsp인증 결과를 받아 부모 페이지의 payment_return() 호출
3CardBillingAuth_Res.jsp인증 결과와 빌링키 확인, 빌링키 저장
4CardAuth.jsp빌링키로 결제. 카드 빌링 결제 참고

#1. 빌링 인증창 호출 (CardBillingAuth_Req.jsp)

java
<%
String LGD_MID       = ("test".equals(CST_PLATFORM) ? "t" : "") + CST_MID;
String LGD_RETURNURL = "https://상점URL/returnurl.jsp";  // 현재 페이지와 같은 프로토콜, 호스트

Map payReqMap = new HashMap();
payReqMap.put("CST_PLATFORM",      CST_PLATFORM);       // test 또는 service
payReqMap.put("CST_MID",           CST_MID);
payReqMap.put("LGD_MID",           LGD_MID);
payReqMap.put("LGD_WINDOW_TYPE",   "iframe");           // 수정 불가
payReqMap.put("LGD_BUYERSSN",      LGD_BUYERSSN);       // 생년월일 6자리 또는 사업자번호 10자리
payReqMap.put("LGD_CHECKSSNYN",    LGD_CHECKSSNYN);     // Y면 인증창에서 입력한 값과 일치하는지 확인
payReqMap.put("LGD_RETURNURL",     LGD_RETURNURL);
payReqMap.put("LGD_PAYWINDOWTYPE", "CardBillingAuth");  // 수정 불가
payReqMap.put("LGD_VERSION",       "JSP_Non-ActiveX_CardBilling");  // 수정·삭제 금지
payReqMap.put("LGD_DOMAIN_URL",    "xpayvvip");         // 수정·삭제 금지

// returnurl.jsp에서 받은 인증 결과를 담을 필드
for (String k : new String[]{"LGD_RESPCODE", "LGD_RESPMSG", "LGD_BILLKEY",
        "LGD_PAYTYPE", "LGD_PAYDATE", "LGD_FINANCECODE", "LGD_FINANCENAME"}) {
    payReqMap.put(k, "");
}
%>

payReqMap의 값은 모두 id="LGD_PAYINFO" Form에 hidden 필드(name과 id가 같은 값)로 넣고, 결제창 스크립트로 인증창을 엽니다.

html
<!-- 테스트 -->
<script language="javascript" src="https://pretest.tosspayments.com:9443/xpay/js/xpay_crossplatform.js" type="text/javascript"></script>
<!-- 서비스
<script language="javascript" src="https://xpayvvip.tosspayments.com/xpay/js/xpay_crossplatform.js" type="text/javascript"></script>
-->
<script type="text/javascript">
var LGD_window_type = 'iframe';

function launchCrossPlatform() {   // 인증 요청 버튼에 연결합니다. 수정 불가
    lgdwin = openXpay(document.getElementById('LGD_PAYINFO'), '<%= CST_PLATFORM %>', LGD_window_type, null, "", "");
}

function getFormObject() {         // Form 이름만 바꿀 수 있습니다.
    return document.getElementById("LGD_PAYINFO");
}

function payment_return() {        // returnurl.jsp가 호출합니다.
    var fDoc = lgdwin.contentWindow || lgdwin.contentDocument;
    if (fDoc.document.getElementById('LGD_RESPCODE').value == "0000") {
        var keys = ["LGD_RESPCODE", "LGD_RESPMSG", "LGD_BILLKEY", "LGD_PAYTYPE",
                    "LGD_PAYDATE", "LGD_FINANCECODE", "LGD_FINANCENAME"];
        for (var i = 0; i < keys.length; i++) {
            document.getElementById(keys[i]).value = fDoc.document.getElementById(keys[i]).value;
        }
        var form = document.getElementById("LGD_PAYINFO");
        form.target = "_self";
        form.action = "CardBillingAuth_Res.jsp";
        form.submit();
    } else {
        alert("LGD_RESPCODE (결과코드) : " + fDoc.document.getElementById('LGD_RESPCODE').value + "\n"
            + "LGD_RESPMSG (결과메시지) : " + fDoc.document.getElementById('LGD_RESPMSG').value);
        closeIframe();
    }
}
</script>

#2. 인증 결과 수신 (returnurl.jsp)

인증창이 인증 결과를 LGD_RETURNURL로 보내면, 받은 값을 hidden 필드에 담고 부모 페이지의 payment_return()을 호출합니다.

html
<body onload="parent.payment_return()">
<form method="post" name="LGD_RETURNINFO" id="LGD_RETURNINFO">
  <input type="hidden" id="LGD_RESPCODE"    name="LGD_RESPCODE"    value="<%= LGD_RESPCODE %>"/>
  <input type="hidden" id="LGD_RESPMSG"     name="LGD_RESPMSG"     value="<%= LGD_RESPMSG %>"/>
  <input type="hidden" id="LGD_BILLKEY"     name="LGD_BILLKEY"     value="<%= LGD_BILLKEY %>"/>
  <input type="hidden" id="LGD_PAYTYPE"     name="LGD_PAYTYPE"     value="<%= LGD_PAYTYPE %>"/>
  <input type="hidden" id="LGD_PAYDATE"     name="LGD_PAYDATE"     value="<%= LGD_PAYDATE %>"/>
  <input type="hidden" id="LGD_FINANCECODE" name="LGD_FINANCECODE" value="<%= LGD_FINANCECODE %>"/>
  <input type="hidden" id="LGD_FINANCENAME" name="LGD_FINANCENAME" value="<%= LGD_FINANCENAME %>"/>
</form>
</body>

#3. 빌링키 확인 (CardBillingAuth_Res.jsp)

java
<%
request.setCharacterEncoding("euc-kr");
String LGD_RESPCODE = request.getParameter("LGD_RESPCODE");
String LGD_RESPMSG  = request.getParameter("LGD_RESPMSG");
String LGD_BILLKEY  = request.getParameter("LGD_BILLKEY");  // 이후 결제 시 카드번호 대신 사용

if ("0000".equals(LGD_RESPCODE)) {
    // 인증 성공. LGD_BILLKEY를 구매자 정보와 함께 DB에 저장합니다.
}
%>

#확인 포인트

  • 이 단계는 빌링키를 발급받는 인증만 하고 결제는 하지 않습니다. 발급받은 빌링키로 결제하는 방법은 카드 빌링 결제를 참고합니다.
  • LGD_WINDOW_TYPE, LGD_PAYWINDOWTYPE, LGD_VERSION, LGD_DOMAIN_URL은 샘플 값 그대로 사용하고 바꾸지 않습니다.
  • LGD_RETURNURL은 인증 요청 페이지와 같은 프로토콜과 호스트여야 합니다. returnurl.jsp가 iframe 안에서 부모 페이지의 payment_return()을 호출하기 때문입니다.
  • 결제창 스크립트는 테스트와 서비스 주소가 다릅니다. 서비스로 전환할 때 스크립트 주소도 함께 바꿉니다.

출처: 샘플 TossPayments_CardBilling_JSP/CardBillingAuth_Req.jsp, returnurl.jsp, CardBillingAuth_Res.jsp

#오류 처리

LGD_RESPCODE가 0000이면 성공입니다. 전체 목록은 응답 코드를 참고하세요.
