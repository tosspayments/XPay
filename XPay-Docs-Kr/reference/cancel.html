#취소·부분취소

LGD_TXNAME Cancel / PartialCancel

승인된 거래를 전체 또는 부분 취소합니다. 전체 취소는 Cancel, 부분 취소는 PartialCancel을 사용합니다.

참고 분할정산 상점은 취소할 때 LGD_DIVIDE_YN을, 부분취소할 때는 LGD_DIVIDE_MID_SUB도 함께 보냅니다. 자세한 내용은 분할정산을 참고합니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

#전체취소 요청 파라미터

파라미터필수최대길이설명
LGD_TXNAME미정-메소드 : CardAuth
LGD_MID필수15TossPayments에서 부여한 상점아이디 토스페이먼츠에서 발급한 상점아이디
LGD_TID미정24TossPayments 거래번호
LGD_CANCELREASON미정-결제 취소환불 사유
LGD_RFBANKCODE미정3환불계좌 은행코드 가상계좌 취소 환불 시 필수
LGD_RFACCOUNTNUM미정15환불계좌 번호 가상계좌 취소 환불 시 필수
LGD_RFCUSTOMERNAME미정32환불계좌 계좌주명 가상계좌 취소 환불 시 필수
LGD_RFPHONE미정15환불요청자 연락처 가상계좌 취소 환불 시 필수

#코드 예제

토스페이먼츠가 제공하는 JSP 샘플 CancelRefund.jsp에서 연동에 필요한 부분만 추린 코드입니다. 다른 언어의 샘플도 동일한 순서를 따릅니다.

java
<%@ page import="lgdacom.XPayClient.XPayClient" %>
<%
String configPath = "C:/lgdacom";

XPayClient xpay = new XPayClient();
if (!xpay.Init(configPath, CST_PLATFORM)) {
    // 환경파일 로드 실패. lgdacom.conf, mall.conf 설치 상태를 확인하세요.
    return;
}

xpay.Init_TX(LGD_MID);
xpay.Set("LGD_TXNAME", "Cancel");
xpay.Set("LGD_TID", LGD_TID);
xpay.Set("LGD_RFBANKCODE", LGD_RFBANKCODE);
xpay.Set("LGD_RFACCOUNTNUM", LGD_RFACCOUNTNUM);
xpay.Set("LGD_RFCUSTOMERNAME", LGD_RFCUSTOMERNAME);
xpay.Set("LGD_RFPHONE", LGD_RFPHONE);

if (xpay.TX()) {
    if ("0000".equals(xpay.m_szResCode)) {
        String respCode = xpay.Response("LGD_RESPCODE", 0);
        String tid      = xpay.Response("LGD_TID", 0);
        if ("0000".equals(respCode)) {
            // 성공. 거래 결과를 DB에 저장하세요.
            boolean isDBOK = true;
            if (!isDBOK) {
                xpay.Rollback("상점 DB 처리 실패로 인한 Rollback [TID:" + tid + "]");
            }
        }
    }
}
%>

#확인 포인트

  • xpay.m_szResCode는 통신 응답코드이고 LGD_RESPCODE는 거래 응답코드입니다. 둘 다 0000이어야 결제 성공입니다. 통신은 성공했지만 거래가 실패한 경우가 있으므로 반드시 두 값을 모두 확인하세요.
  • xpay.Response(파라미터명, 0)으로 응답값을 꺼냅니다. 두 번째 인자는 인덱스이며 같은 이름의 응답이 여러 개인 경우에만 0이 아닌 값을 사용합니다.
  • 승인은 성공했지만 상점 DB 저장에 실패했다면 xpay.Rollback()으로 자동취소하세요. 이 처리를 빠뜨리면 고객은 결제됐는데 주문이 없는 상태가 됩니다.
  • 응답 전체를 순회하려면 xpay.ResponseNameCount()와 xpay.ResponseName(i)를 사용합니다.

출처: 샘플 TossPayments_CancelRefund_JSP/TossPayments_CancelRefund_JSP/CancelRefund.jsp

#오류 처리

LGD_RESPCODE가 0000이면 성공입니다. 전체 목록은 응답 코드를 참고하세요.
