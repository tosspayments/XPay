#자체창 결제

LGD_TXNAME PaymentByKey · LGD_WINDOW_TYPE 자체창(허브형)

통합결제창을 사용하지 않고 개별 카드사 자체창 또는 간편결제를 직접 호출하는 방식입니다. 인증 이후 승인 흐름은 통합결제창과 같습니다.

이 페이지는 PC와 모바일을 함께 다룹니다. 모바일에서만 사용하는 파라미터는 모바일 전용 배지로 표시했습니다.
필수 여부는 결제연동스펙_표준창_v1.0.2를 기준으로 합니다. 조건부 필수는 특정 결제수단에서만 필수인 항목입니다. 미정은 표준창 스펙에 표기가 없어 확인이 필요한 항목입니다.

#결제 흐름

  1. 결제창 호출 요청 파라미터를 Form으로 구성해 결제창을 엽니다.
  2. 구매자가 인증을 마치면 인증 응답으로 LGD_PAYKEY가 전달됩니다.
  3. LGD_PAYKEY로 XPayClient를 통해 승인을 요청하고 승인 응답을 받습니다.

호출 순서는 XPayClient 호출 패턴을 참고하세요.

LGD_KVPMISPWAPURL 모바일 전용필수255ISP 인증완료 후 사용자에게 보여지는 앱 스키마를 설정합니다. APP 결제는 안드로이드, iOS 에 따라 다른 값을 셋팅해야 합니다. 예) 안드로이드 : LGD_KVPMISPWAPURL = "" (빈값 고정) 예) iOS : LGD_KVPMISPWAPURL = "가맹점 app scheme" (가맹점 앱 스키마를 입력) ISP 비동기방식 사용시, 승인완료후 사용자에게 보여지는 결제성공 화면페이지 URL * 승인성공시에만 호출되는 URL로, 결제요청시 GET방식으로 넘겨주는 파라미터가 그대로 전달됨. DB처리후 결과값(LGD_KVPMISPNOTEURL)을 확인하여 결제성공 화면 처리함. ISP 동기방식 사용시에도 파라미터는 전달되어야 함
LGD_KVPMISPCANCELURL 모바일 전용필수255ISP 인증 취소(또는 실패)할 경우 사용자에게 보여지는 앱 스키마를 설정합니다. APP 결제는 안드로이드, iOS 에 따라 다른 값을 셋팅해야 합니다. 예) 안드로이드 : LGD_KVPMISPCANCELURL = "" (빈값 고정) 예) iOS : LGD_KVPMISPCANCELURL = "가맹점 app scheme" (가맹점 앱 스키마를 입력) ISP 비동기방식 사용시, 결제중 ISP 앱에서 취소시에 사용자에게 보여지는 취소 페이지 URL. ISP 동기방식 사용시에도 파라미터는 전달되어야 함
LGD_MPILOTTEAPPCARDWAPURL 모바일 전용미정-롯데카드 인증 이후 사용자에게 보여지는 앱 스키마를 설정합니다. iOS 환경의 고객사 APP 에서 결제 시 필수 LGD_KVPMISPWAPURL 과는 별개로 사용되는 파라미터 입니다. 예) LGD_MPILOTTEAPPCARDWAPURL = "가맹점 app scheme" (가맹점 앱 스키마를 입력)
LGD_MALL_APP_NAME 모바일 전용미정-삼성, 현대, 신한카드 인증 이후 사용자에게 보여지는 앱 스키마를 설정합니다. iOS 환경의 고객사 APP 에서 결제 시 필수 LGD_KVPMISPWAPURL 과는 별개로 사용되는 파라미터 입니다. 예) LGD_MALL_APP_NAME = "가맹점 app scheme" (가맹점 앱 스키마를 입력)
