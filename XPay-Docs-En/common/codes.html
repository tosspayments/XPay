#Response codes

LGD_RESPCODE is 0000 on success; any other value indicates failure. The failure reason is in LGD_RESPMSG.

Configuration file errors occur before the payment request reaches the server.

CodeMeaningAction
0000Success-
10001Could not read the lgdacom directory setting.Make sure the configPath passed when initializing XPayClient is the absolute path of the lgdacom folder.
10002Cannot find the mall.conf file.Check that lgdacom/conf/mall.conf exists and is readable.
10003Cannot find the lgdacom.conf file.Check that lgdacom/conf/lgdacom.conf exists and is readable.

Other payment failure codes vary by payment method and institution. For the complete list, see the separate error code documentation for each payment method.
