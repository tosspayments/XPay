#Transaction response fields

This page defines the fields returned in the payment approval response and shows which payment methods populate each value. Transaction pages refer to this page, and additional fields for each transaction are defined on the corresponding page.

If Supported payment methods is Common, the value is returned for all payment methods. Fields marked for specific payment methods are empty or not returned for other payment methods.
