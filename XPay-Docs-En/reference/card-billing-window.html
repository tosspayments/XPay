#Billing key issuance via payment window

LGD_TXNAME CardAuth

Issues a billing key after buyer authentication in the unified payment window. The method is the same on PC and mobile.

For the call sequence, see XPayClient call pattern.

#Billing authentication window request parameters

ParameterRequiredMax lengthDescription
CST_PLATFORMTBD-Selects the live or test environment of the server that communicates with Toss Payments. service (live environment) or test (test environment).
CST_MIDTBD15Merchant ID contracted with Toss Payments
LGD_MIDRequired15Merchant ID issued by Toss Payments
LGD_DOMAIN_URLTBD-Module connection URL. Use the fixed value "xpayvvip" (opens the payment window over TLS 1.2). This parameter is required to open the payment window (authentication) over TLS 1.2. Do not change or remove it.
LGD_WINDOW_TYPETBD-How the payment window is opened. Use the fixed value for the device that opens the window: "iframe" for PC, "submit" for mobile devices.
LGD_RETURNURLRequired255URL of the page that receives the authentication result. Must use the same protocol and host as the authentication page (place it in the same directory as the authentication page).
LGD_PAYWINDOWTYPETBD-Authentication request type. Use "CardBillingAuth" for PC and "CardBillingAuth_smartphone" for mobile devices.
LGD_VERSIONTBD-Module information. Omitting this parameter does not block the service, but it is used to identify which service is in use. Do not change or remove it.
LGD_ENCODINGOptional-Sets the encoding used when opening the payment window (default: EUC-KR). Example: UTF-8. To use UTF-8 for the server response to the approval request after authentication, set output_UTF8 = 1 in mall.conf (0 for EUC-KR). Default EUC-KR. Use only when opening the window by form submit with an encoding other than EUC-KR.
LGD_ENCODING_RETURNURLOptional-Character encoding for the authentication result sent to LGD_RETURNURL. Default EUC-KR. If you send UTF-8, values are delivered to LGD_RETURNURL in UTF-8.
LGD_BUYERSSNTBD6Buyer's date of birth (or business registration number)
LGD_CHECKSSNYNTBD1Whether to verify the buyer's date of birth. Set to Y to verify (default: N).

#Code example

The following code extracts the parts needed for billing key issuance from the JSP sample TossPayments_CardBilling_JSP provided by Toss Payments. Samples in other languages follow the same order.

OrderFileRole
1CardBillingAuth_Req.jspOpens the billing authentication window
2returnurl.jspReceives the authentication result and calls payment_return() on the parent page
3CardBillingAuth_Res.jspChecks the authentication result and billing key, and stores the billing key
4CardAuth.jspPays with the billing key. See Card billing payment.

#1. Open the billing authentication window (CardBillingAuth_Req.jsp)

java
<%
String LGD_MID       = ("test".equals(CST_PLATFORM) ? "t" : "") + CST_MID;
String LGD_RETURNURL = "https://merchant-url/returnurl.jsp";  // Same protocol and host as the current page

Map payReqMap = new HashMap();
payReqMap.put("CST_PLATFORM",      CST_PLATFORM);       // test or service
payReqMap.put("CST_MID",           CST_MID);
payReqMap.put("LGD_MID",           LGD_MID);
payReqMap.put("LGD_WINDOW_TYPE",   "iframe");           // Do not change
payReqMap.put("LGD_BUYERSSN",      LGD_BUYERSSN);       // Date of birth (6 digits) or business registration number (10 digits)
payReqMap.put("LGD_CHECKSSNYN",    LGD_CHECKSSNYN);     // If Y, checks that it matches the value entered in the window
payReqMap.put("LGD_RETURNURL",     LGD_RETURNURL);
payReqMap.put("LGD_PAYWINDOWTYPE", "CardBillingAuth");  // Do not change
payReqMap.put("LGD_VERSION",       "JSP_Non-ActiveX_CardBilling");  // Do not change or remove
payReqMap.put("LGD_DOMAIN_URL",    "xpayvvip");         // Do not change or remove

// Fields for the authentication result received from returnurl.jsp
for (String k : new String[]{"LGD_RESPCODE", "LGD_RESPMSG", "LGD_BILLKEY",
        "LGD_PAYTYPE", "LGD_PAYDATE", "LGD_FINANCECODE", "LGD_FINANCENAME"}) {
    payReqMap.put(k, "");
}
%>

Put every value in payReqMap in hidden fields of the form with id="LGD_PAYINFO" (with the same name and id), and open the authentication window with the payment window script.

html
<!-- Test -->
<script language="javascript" src="https://pretest.tosspayments.com:9443/xpay/js/xpay_crossplatform.js" type="text/javascript"></script>
<!-- Production
<script language="javascript" src="https://xpayvvip.tosspayments.com/xpay/js/xpay_crossplatform.js" type="text/javascript"></script>
-->
<script type="text/javascript">
var LGD_window_type = 'iframe';

function launchCrossPlatform() {   // Bound to the authentication request button. Do not change.
    lgdwin = openXpay(document.getElementById('LGD_PAYINFO'), '<%= CST_PLATFORM %>', LGD_window_type, null, "", "");
}

function getFormObject() {         // You can change only the form name.
    return document.getElementById("LGD_PAYINFO");
}

function payment_return() {        // Called by returnurl.jsp.
    var fDoc = lgdwin.contentWindow || lgdwin.contentDocument;
    if (fDoc.document.getElementById('LGD_RESPCODE').value == "0000") {
        var keys = ["LGD_RESPCODE", "LGD_RESPMSG", "LGD_BILLKEY", "LGD_PAYTYPE",
                    "LGD_PAYDATE", "LGD_FINANCECODE", "LGD_FINANCENAME"];
        for (var i = 0; i < keys.length; i++) {
            document.getElementById(keys[i]).value = fDoc.document.getElementById(keys[i]).value;
        }
        var form = document.getElementById("LGD_PAYINFO");
        form.target = "_self";
        form.action = "CardBillingAuth_Res.jsp";
        form.submit();
    } else {
        alert("LGD_RESPCODE (result code) : " + fDoc.document.getElementById('LGD_RESPCODE').value + "\n"
            + "LGD_RESPMSG (result message) : " + fDoc.document.getElementById('LGD_RESPMSG').value);
        closeIframe();
    }
}
</script>

#2. Receive the authentication result (returnurl.jsp)

When the authentication window sends the result to LGD_RETURNURL, put the received values in hidden fields and call payment_return() on the parent page.

html
<body onload="parent.payment_return()">
<form method="post" name="LGD_RETURNINFO" id="LGD_RETURNINFO">
  <input type="hidden" id="LGD_RESPCODE"    name="LGD_RESPCODE"    value="<%= LGD_RESPCODE %>"/>
  <input type="hidden" id="LGD_RESPMSG"     name="LGD_RESPMSG"     value="<%= LGD_RESPMSG %>"/>
  <input type="hidden" id="LGD_BILLKEY"     name="LGD_BILLKEY"     value="<%= LGD_BILLKEY %>"/>
  <input type="hidden" id="LGD_PAYTYPE"     name="LGD_PAYTYPE"     value="<%= LGD_PAYTYPE %>"/>
  <input type="hidden" id="LGD_PAYDATE"     name="LGD_PAYDATE"     value="<%= LGD_PAYDATE %>"/>
  <input type="hidden" id="LGD_FINANCECODE" name="LGD_FINANCECODE" value="<%= LGD_FINANCECODE %>"/>
  <input type="hidden" id="LGD_FINANCENAME" name="LGD_FINANCENAME" value="<%= LGD_FINANCENAME %>"/>
</form>
</body>

#3. Check the billing key (CardBillingAuth_Res.jsp)

java
<%
request.setCharacterEncoding("euc-kr");
String LGD_RESPCODE = request.getParameter("LGD_RESPCODE");
String LGD_RESPMSG  = request.getParameter("LGD_RESPMSG");
String LGD_BILLKEY  = request.getParameter("LGD_BILLKEY");  // Used instead of the card number for later payments

if ("0000".equals(LGD_RESPCODE)) {
    // Authentication succeeded. Save LGD_BILLKEY to the DB with the buyer information.
}
%>

#Key points

  • This step only authenticates to issue a billing key; it does not make a payment. To pay with the issued billing key, see Card billing payment.
  • Use LGD_WINDOW_TYPE, LGD_PAYWINDOWTYPE, LGD_VERSION, and LGD_DOMAIN_URL exactly as in the sample.
  • LGD_RETURNURL must use the same protocol and host as the authentication request page, because returnurl.jsp calls payment_return() on the parent page from inside the iframe.
  • The payment window script URL differs between test and production. When you switch to production, change the script URL as well.

Source: samples TossPayments_CardBilling_JSP/CardBillingAuth_Req.jsp, returnurl.jsp, and CardBillingAuth_Res.jsp

#Error handling

LGD_RESPCODE is 0000 on success. For the complete list, see Response codes.
