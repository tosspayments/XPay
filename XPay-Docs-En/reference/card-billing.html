#Card billing payment

LGD_TXNAME CardAuth

An automatic payment requested with an issued LGD_BILLKEY. It uses the same LGD_TXNAME as non-authenticated payment, but uses a billing key instead of a card number.

For the call sequence, see XPayClient call pattern.

#Code example

The following code extracts the parts needed for billing key payments from the JSP sample CardAuth.jsp provided by Toss Payments. Samples in other languages follow the same order.

java
<%@ page import="lgdacom.XPayClient.XPayClient" %>
<%
String configPath = "C:/lgdacom";  // Place this in a path that is not accessible from the web.

XPayClient xpay = new XPayClient();
if (!xpay.Init(configPath, CST_PLATFORM)) {
    // Initialization failed. Check the lgdacom.conf and mall.conf installation and the "MID = mertkey" entry in mall.conf.
    return;
}

xpay.Init_TX(LGD_MID);
xpay.Set("LGD_TXNAME", "CardAuth");
xpay.Set("LGD_OID", LGD_OID);
xpay.Set("LGD_AMOUNT", LGD_AMOUNT);
xpay.Set("LGD_PAN", LGD_BILLKEY);                // Issued billing key instead of the card number
xpay.Set("LGD_INSTALL", LGD_INSTALL);            // Installment months (lump sum: 00)
xpay.Set("VBV_ECI", "010");
xpay.Set("LGD_BUYERPHONE", LGD_BUYERPHONE);
xpay.Set("LGD_BUYER", LGD_BUYER);
xpay.Set("LGD_BUYERID", LGD_BUYERID);
xpay.Set("LGD_BUYERIP", request.getRemoteAddr());
xpay.Set("LGD_PRODUCTINFO", LGD_PRODUCTINFO);

if (xpay.TX()) {
    if ("0000".equals(xpay.m_szResCode)) {
        // Payment succeeded. Save the result to the DB.
        boolean isDBOK = true;  // false if DB processing fails
        if (!isDBOK) {
            xpay.Rollback("Rollback due to merchant DB processing failure [TID:" + xpay.Response("LGD_TID", 0)
                + ",MID:" + xpay.Response("LGD_MID", 0) + ",OID:" + xpay.Response("LGD_OID", 0) + "]");
        }
    } else {
        // Payment failed. Save the failure to the DB.
    }
} else {
    // API request failed. Check xpay.m_szResCode and xpay.m_szResMsg for the reason and save the failure to the DB.
}
%>

#Key points

  • A billing key payment is the same CardAuth transaction as Card non-authenticated payment. The only difference is that you put the issued LGD_BILLKEY in LGD_PAN instead of a card number.
  • The sample CardAuth.jsp is the same file used for non-authenticated payments, so it includes key-in handling for the expiration date, password, and date of birth. Billing key payments do not send these values, so the code above omits them.
  • If xpay.TX() returns true, communication succeeded; determine whether the payment succeeded by checking that xpay.m_szResCode is 0000.
  • If the payment succeeds but saving to the merchant database fails, cancel automatically with xpay.Rollback(). If you skip this, the buyer is charged but no order exists.
  • To issue a billing key through the payment window, see Billing key issuance via payment window.

Source: sample TossPayments_CardBilling_JSP/CardAuth.jsp
