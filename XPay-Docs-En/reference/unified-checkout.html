#Unified payment window

LGD_TXNAME PaymentByKey · LGD_WINDOW_TYPE Unified payment window

Opens the unified payment window provided by Toss Payments for payment. When the buyer selects a payment method and completes authentication in the window, LGD_PAYKEY is issued, and you request approval with this key.

This page covers both PC and mobile. Parameters used only on mobile are marked with the Mobile only badge.
Required status is based on Standard payment window integration specification v1.0.2. Conditional means required only for specific payment methods. TBD means the standard specification does not state the requirement and it needs to be confirmed.

#Payment flow

  1. Build the payment window request parameters in a form and open the payment window.
  2. When the buyer completes authentication, LGD_PAYKEY is delivered in the authentication response.
  3. Request approval with LGD_PAYKEY through XPayClient and receive the approval response.

For the call sequence, see XPayClient call pattern.
