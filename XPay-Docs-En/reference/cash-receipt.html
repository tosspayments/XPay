#Cash receipts

LGD_TXNAME CashReceipt

Issues a cash receipt or cancels an issued cash receipt.

For the call sequence, see XPayClient call pattern.

#Cash receipt issuance request parameters

ParameterRequiredMax lengthDescription
LGD_TXNAMETBD-Transaction name. Fixed to CashReceipt.
LGD_MIDRequired15Merchant ID issued by Toss Payments
LGD_METHODTBD-Request type. AUTH: issue, CANCEL: cancel
LGD_PAYTYPETBD6Payment method code. SC0030: bank transfer, SC0040: virtual account, SC0100: standalone bank deposit
LGD_OIDRequired64Merchant order ID (transaction ID created by the merchant). Letters and digits only; must be unique per order.
LGD_TIDTBD24Toss Payments transaction ID
LGD_AMOUNTRequired12Payment amount. Digits only, without separators such as ','.
LGD_CASHCARDNUMTBD20Cash receipt identification number. Income deduction: resident registration number, mobile phone number, or cash receipt card number. Expense proof: business registration number.
LGD_CASHRECEIPTUSETBD1Cash receipt purpose (1: income deduction, 2: expense proof, 0: not issued)
LGD_CUSTOM_BUSINESSNUMTBD10Business registration number of the cash receipt issuer. Applies only to cash receipt issuance integrations.
LGD_CUSTOM_MERTPHONETBD11Phone number of the cash receipt issuer. Applies only to cash receipt issuance integrations.
LGD_CUSTOM_MERTNAMETBD20Merchant name of the cash receipt issuer. Applies only to cash receipt issuance integrations.
LGD_CUSTOM_CEONAMETBD12Representative of the cash receipt issuer. Applies only to cash receipt issuance integrations.
LGD_CUSTOM_MERTADDRESSTBD40Address of the cash receipt issuer
LGD_TRADEDATETBD14Cash receipt issue date (yyyyMMddhhmmss). Can be set up to 2 days before the transaction date (= cash receipt issue date, D-2). If you send a date beyond the allowed range, issuance still returns success, but the National Tax Service lookup returns an error, so use a date no more than 2 days earlier.
LGD_PRODUCTINFORequired128Name of the purchased product
LGD_TAXFREEAMOUNTOptional9Tax-free amount within the total payment amount (LGD_AMOUNT). Available only with a "partial tax exemption" contract. Example 1: if the product costs 15,000 KRW and the tax-free amount is 15,000 KRW, LGD_TAXFREEAMOUNT = 15000. Example 2: if multiple products under one order ID total 45,000 KRW and some are tax-free (35,000 KRW in total), LGD_TAXFREEAMOUNT = 35000.
LGD_VATTBD12Merchant-defined VAT amount. Use this when the cash receipt VAT calculated by Toss Payments does not match the VAT calculated by the merchant and you need to apply the merchant's VAT.
LGD_SEQNOTBD3Virtual account sequence number. Fixed value: 001 (when the payment method is virtual account [LGD_PAYTYPE=SC0040] or standalone bank deposit [LGD_PAYTYPE=SC0100]). For merchants using banks that allow overpayment or underpayment, cash receipts are issued in deposit order. For standalone bank deposit receipts, always set "001" to prevent duplicate use of the order ID (LGD_OID).

#Code example

The following code extracts the parts needed for integration from the JSP sample CashReceipt.jsp provided by Toss Payments. Samples in other languages follow the same order.

java
<%@ page import="lgdacom.XPayClient.XPayClient" %>
<%
String configPath = "C:/lgdacom";  // Place this in a path that is not accessible from the web.

XPayClient xpay = new XPayClient();
if (!xpay.Init(configPath, CST_PLATFORM)) {
    // Failed to load the configuration files. Check the lgdacom.conf and mall.conf installation.
    return;
}

xpay.Init_TX(LGD_MID);
xpay.Set("LGD_TXNAME", "CashReceipt");
xpay.Set("LGD_METHOD", LGD_METHOD);    // AUTH: issue, CANCEL: cancel
xpay.Set("LGD_PAYTYPE", LGD_PAYTYPE);  // SC0030: bank transfer, SC0040: virtual account, SC0100: standalone bank deposit

if (LGD_METHOD.equals("AUTH")) {       // Cash receipt issuance request
    xpay.Set("LGD_OID", LGD_OID);
    xpay.Set("LGD_CUSTOM_MERTNAME", LGD_CUSTOM_MERTNAME);
    xpay.Set("LGD_CUSTOM_BUSINESSNUM", LGD_CUSTOM_BUSINESSNUM);
    xpay.Set("LGD_CUSTOM_MERTPHONE", LGD_CUSTOM_MERTPHONE);
    xpay.Set("LGD_CASHCARDNUM", LGD_CASHCARDNUM);
    xpay.Set("LGD_AMOUNT", LGD_AMOUNT);
    xpay.Set("LGD_CASHRECEIPTUSE", LGD_CASHRECEIPTUSE);  // 1: income deduction, 2: expense proof

    if (LGD_PAYTYPE.equals("SC0030")) {          // Previously paid bank transfer
        xpay.Set("LGD_TID", LGD_TID);
    } else if (LGD_PAYTYPE.equals("SC0040")) {   // Previously paid virtual account
        xpay.Set("LGD_TID", LGD_TID);
        xpay.Set("LGD_SEQNO", "001");
    } else {                                     // Standalone bank deposit
        xpay.Set("LGD_PRODUCTINFO", LGD_PRODUCTINFO);
    }
} else {                               // Cash receipt cancellation request
    xpay.Set("LGD_TID", LGD_TID);
    if (LGD_PAYTYPE.equals("SC0040")) {          // Virtual account
        xpay.Set("LGD_SEQNO", "001");
    }
}

if (xpay.TX()) {
    // Communication succeeded. Determine the transaction result from LGD_RESPCODE.
    String respCode = xpay.Response("LGD_RESPCODE", 0);
    String respMsg  = xpay.Response("LGD_RESPMSG", 0);
    String tid      = xpay.Response("LGD_TID", 0);
    if ("0000".equals(respCode)) {
        // Issuance or cancellation succeeded. Save the result to the DB.
    } else {
        // Issuance or cancellation failed. Check respMsg for the reason.
    }
} else {
    // API request failed. Check xpay.m_szResCode and xpay.m_szResMsg for the reason.
}
%>

#Key points

  • A single page distinguishes issuance (AUTH) from cancellation (CANCEL) with LGD_METHOD. Send the merchant information (LGD_CUSTOM_*), identification number (LGD_CASHCARDNUM), amount, and purpose only when issuing.
  • The values to send depend on the payment method (LGD_PAYTYPE).
Payment methodIssue (AUTH)Cancel (CANCEL)
SC0030 Bank transferLGD_TIDLGD_TID
SC0040 Virtual accountLGD_TID, LGD_SEQNO=001LGD_TID, LGD_SEQNO=001
SC0100 Standalone bank depositLGD_PRODUCTINFOLGD_TID
  • LGD_TID is the Toss Payments transaction ID of the previously paid transaction. Do not confuse it with the LGD_PAYKEY received at payment approval.
  • The result of xpay.TX() indicates whether communication succeeded, and LGD_RESPCODE indicates the transaction result. Communication can succeed while issuance or cancellation fails, so check both values.
  • To iterate over the entire response, use xpay.ResponseNameCount() and xpay.ResponseName(i).

Source: sample TossPayments_no_session_JSP/CashReceipt.jsp

#Error handling

LGD_RESPCODE is 0000 on success. For the complete list, see Response codes.
