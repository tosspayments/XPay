Store images for the documents in this folder.

How to reference them from a document:

  From docs/reference/card-keyin.md
    ![Payment window](../images/checkout-pc.png)

  From docs/README.md
    ![Payment window](images/checkout-pc.png)

To add a caption, put the description in double quotes after the path.
    ![Payment window](../images/checkout-pc.png "Figure 1. PC unified payment window")

To show an image without a border, include no-border in the alt text.
    ![Payment flow no-border](../images/flow.png)

Use lowercase letters and hyphens in file names. Example: checkout-pc.png
