#Interest-free installment lookup

Direct HTTPS call · eventDiv2 getNoInterest

Retrieves the interest-free installment information for each card company that applies on a specified date. You receive, in XML, the minimum payment amount and installment months available for interest-free installments for each card company, which you can use to show interest-free information on your payment page.

This feature is called directly over HTTPS without the XPayClient library. Because the call method differs, XPayClient call pattern does not apply.

#Request

text
GET https://pgweb.tosspayments.com/MpFlowCtrl?eventDiv1=nointerestapi&eventDiv2=getNoInterest&LGD_MERTID={MID}&LGD_DATE={yyyyMMdd}&LGD_HASH_DATA={hash}
ParameterRequiredDescription
eventDiv1RequiredFixed to nointerestapi. Do not change.
eventDiv2RequiredFixed to getNoInterest. Do not change.
LGD_MERTIDRequiredMerchant ID
LGD_DATERequiredDate to look up (yyyyMMdd)
LGD_HASH_DATARequiredSecurity code that prevents unauthorized links. SHA-512 value of the merchant ID concatenated with the mertkey. See Hash generation.

#Hash generation

text
LGD_HASH_DATA = SHA-512( MID + mertkey )  // Hexadecimal string, 128 characters

Unlike the key (MD5) used for transaction and settlement lookups, this uses SHA-512. Look up the mertkey in Find your mertkey. Because the hash is created from the mertkey, always call the lookup from the merchant server and never expose the hash in a browser or app.

#curl example

This example retrieves the interest-free installment information as of September 14, 2026 and saves it to a file.

bash
MID="your MID"
MERTKEY="your mertkey"
LGD_DATE="20260914"

# LGD_HASH_DATA = SHA-512(MID + mertkey). On macOS, use `shasum -a 512` instead of sha512sum.
HASH=$(printf '%s%s' "$MID" "$MERTKEY" | sha512sum | awk '{print $1}')

curl -sS -G "https://pgweb.tosspayments.com/MpFlowCtrl" \
  --data-urlencode "eventDiv1=nointerestapi" \
  --data-urlencode "eventDiv2=getNoInterest" \
  --data-urlencode "LGD_MERTID=${MID}" \
  --data-urlencode "LGD_DATE=${LGD_DATE}" \
  --data-urlencode "LGD_HASH_DATA=${HASH}" \
  -o "nointerest_${LGD_DATE}.xml"

# The response is EUC-KR. Convert it to view it as UTF-8.
iconv -f EUC-KR -t UTF-8 "nointerest_${LGD_DATE}.xml"

#Response format

The response is XML encoded in EUC-KR. It contains one <CardInfo> element for each card company.

ElementDescription
CardCodeCard company code
CardNameCard company name
CardTypeCard authentication method (for example, ISP, VBV)
CardEventInterest-free installment months by minimum payment amount. See How to read CardEvent.

#How to read CardEvent

CardEvent consists of segments in the format minimum amount-months:months:…:, joined with ^.

text
5-2:3:4:5:^20-10:
SegmentMeaning
5-2:3:4:5:2-, 3-, 4-, and 5-month interest-free installments for a minimum amount of 5 or more
20-10:10-month interest-free installments for a minimum amount of 20 or more

#Response example

text
<?xml version="1.0" encoding="EUC-KR" ?>
<wemake0003>
  <CardInfo>
    <CardCode>11</CardCode>
    <CardName>KB국민</CardName>
    <CardType>ISP</CardType>
    <CardEvent>5-2:3:4:5:^20-10:</CardEvent>
  </CardInfo>
  <CardInfo>
    <CardCode>21</CardCode>
    <CardName>하나(외환)</CardName>
    <CardType>VBV</CardType>
    <CardEvent>10-2:3:4:5:^20-10:</CardEvent>
  </CardInfo>
</wemake0003>

#Key points

  • Interest-free installment information can change by date, so look it up for the date you display it on your payment page.
  • Each segment of CardEvent ends with :. Exclude empty values when splitting the installment months.
  • The response is EUC-KR, so convert the encoding when parsing it in a UTF-8 environment.
